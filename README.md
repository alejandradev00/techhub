# TechHub Store
Proyecto final para el Taller de Aplicaciones en Internet.

Funcionalidades
MVC: Arquitectura limpia y organizada.
Carrito Kawaii: Gestión de productos con AJAX (sin recarga de página).
Control de Stock: Validación automática para productos agotados.
Seguridad: Registro y Login con manejo de sesiones.

Instalación
1. Clonar el repositorio.
2. Importar el archivo `techhub_db.sql` en phpMyAdmin.
3. Configurar la conexión en `app/Core/Database.php`.
